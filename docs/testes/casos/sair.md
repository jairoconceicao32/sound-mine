# CT04 — Sair do programa

## Título:
Sair do programa.

## Descrição:
Verificar se o programa permite encerrar sua execução corretamente por meio da opção Sair, disponível no menu principal.

## Pré-requisitos:
- Ter o Sound Mine instalado;
- Ter o programa aberto no menu principal.

## Passos para a reprodução:
1. Acessar o menu principal;
2. Navegar até a opção Sair utilizando as teclas de seta;
3. Verificar se a opção selecionada é anunciada corretamente pelo NVDA;
4. Ativar a opção utilizando a tecla Enter;
5. Verificar se o programa foi encerrado.

## Comportamento esperado — caminho feliz:
- A opção Sair deve estar disponível no menu principal;
- A opção deve ser identificada corretamente pelo NVDA;
- Ao pressionar Enter, o programa deve encerrar sua execução normalmente;
- O encerramento não deve apresentar erros.

## Comportamento esperado — caminho não feliz:
- Caso o programa não consiga encerrar sua execução, não deve apresentar travamentos;
- O programa não deve apresentar mensagens de erro inesperadas durante o encerramento;
- O encerramento não deve deixar processos desnecessários em execução.

## Observações:
Validar o encerramento do programa por meio da opção Sair, verificando se a aplicação finaliza corretamente.
